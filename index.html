Panduan Web Hosting PHP (my.php.id)

Gunakan web hosting PHP pribadi Anda (seperti di https://my.php.id/ atau cPanel hosting lainnya) untuk streaming lagu dan lirik tanpa limit:

⚡ Langkah 1: Buat Folder di cPanel / File Manager

Buka File Manager di cPanel hosting Anda, masuk ke folder public_html/, lalu buat struktur folder berikut: 

public_html/
└── karaoke/
    ├── api.php      <-- script di bawah
    └── songs/        <-- file .mp3 & .lrc

⚡ Langkah 2: Upload File api.php

File api.php sudah tersedia di folder proyek Anda: php-server/api.php. Anda juga bisa menyalin langsung kode script di bawah ini:

⚡ Langkah 3: Masukkan URL di Tab Cloud Server

Masukkan URL ke kolom URL Endpoint api.php (misal: https://domainanda.my.php.id/karaoke/api.php) lalu klik Simpan & Hubungkan. Seluruh lagu Anda akan langsung terdeteksi!
