Tambah Lagu dari Google Drive

Pastikan file di Google Drive Anda diatur ke "Siapa saja yang memiliki link dapat melihat".

Panduan Google Drive Online Search

Google Drive memblokir akses langsung dari aplikasi luar karena proteksi keamanan (CORS). Agar aplikasi SUSHEE dapat mencari semua lagu di folder Anda, gunakan salah satu cara di bawah:

⭐ Cara 1: Google Apps Script (Rekomendasi - 1 Menit, 100% Gratis)

  1. Buka script.google.com lalu klik New project (Proyek baru).
  2. Hapus semua teks di sana, lalu copy-paste kode script di bawah ini.
  3. Klik Deploy (Terapkan) > New deployment (Penerapan baru).
  4. Pilih tipe Web app (Aplikasi Web):
    • Execute as: Me (Saya)
    • Who has access: Anyone (Siapa saja)
  5. Klik Deploy, lalu salin URL yang berakhiran /exec dan tempel ke kolom Web App URL di pengaturan SUSHEE.

⚡ Cara 2: Tombol "+ Tambah Link Lagu GDrive" (Tanpa Koding)

Cukup buka file lagu Anda di Google Drive, klik Bagikan (Share) > Salin link (pastikan akses: Siapa saja yang memiliki link), lalu klik tombol "+ Tambah Link Lagu GDrive" di aplikasi SUSHEE. Lagu akan langsung tersimpan di database HP Anda.
